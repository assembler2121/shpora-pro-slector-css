Справочник: CSS Псевдоклассы и Псевдоэлементы

Псевдоклассы (:) определяют состояние или структуру элемента, а псевдоэлементы (::) позволяют обратиться к специфической части элемента или создать новые виртуальные блоки.

Псевдоклассы (одно двоеточие :)

Состояния пользователя и интерактивность

  • :hover — элемент под курсором мыши. Применяется для создания интерактивных эффектов при наведении.
  • :active — элемент в момент активации (например, зажата левая кнопка мыши на кнопке).
  • :focus — элемент в фокусе (например, активное поле ввода или выделенная ссылка).
  • :focus-visible — срабатывает только тогда, когда браузер считает нужным показать контур фокуса (идеально для стилизации навигации с клавиатуры, не мешая пользователям мыши).
  • :focus-within — применяется к родителю, если любой вложенный в него элемент получил фокус (удобно для подсветки всей формы, когда активен один инпут).

Ссылки и история

  • :link — непосещённая ссылка (работает только для тегов <a> с атрибутом href).
  • :visited — ссылка, по которой пользователь уже переходил (из соображений безопасности браузеры сильно ограничивают стили для этого состояния, разрешая менять в основном только цвет).
  • :any-link — соответствует любой ссылке (объединяет :link и :visited).

Состояния форм и элементов ввода

  • :checked — выбранный чекбокс (type="checkbox"), радиокнопка (type="radio") или элемент <option> в селекте.
  • :disabled — заблокированный, неактивный элемент интерфейса (нельзя кликнуть или сфокусироваться).
  • :enabled — включённый (активный) элемент интерфейса, готовый к взаимодействию.
  • :required — поле формы с атрибутом required (обязательное для заполнения).
  • :optional — необязательное поле формы (без атрибута required).
  • :valid / :invalid — поле, содержимое которого прошло или не прошло встроенную HTML5-валидацию (например, правильность email).
  • :read-only / :read-write — элементы только для чтения (с атрибутом readonly) или доступные для редактирования.
  • :placeholder-shown — поле ввода, которое в данный момент пустое и показывает плейсхолдер. Как только пользователь вводит первый символ, псевдокласс перестает работать.
  • :blank — пустой элемент ввода. Примечание: на данный момент экспериментальная функция со слабой поддержкой браузерами.

Структурные и позиционные селекторы

  • :first-child — самый первый дочерний элемент внутри своего родителя.
  • :last-child — самый последний дочерний элемент внутри родителя.
  • :only-child — единственный дочерний элемент (у родителя больше нет других потомков).
  • :first-of-type — первый элемент определённого тега среди своих соседей (например, первый <p> в блоке, даже если перед ним есть <h1>).
  • :last-of-type — последний элемент определённого тега среди соседей.
  • :only-of-type — единственный элемент своего типа внутри родителя.
  • :nth-child(n) — выбор элементов по формуле. Например, :nth-child(odd) для нечётных, :nth-child(even) для чётных, или :nth-child(3n) для каждого третьего.
  • :nth-last-child(n) — то же самое, но отсчёт начинается с конца списка.
  • :nth-of-type(n) — выбор по формуле, но считаются только элементы указанного типа.
  • :empty — полностью пустой элемент (внутри нет ни других тегов, ни пробелов, ни текста).

Логические псевдоклассы и функции

  • :not(selector) — отрицание. Исключает элементы, подходящие под переданный селектор (например, p:not(.highlight) — все абзацы, кроме выделенных).
  • :is(selectorList) — упрощает группировку селекторов и сокращает код. Принимает специфичность самого "тяжёлого" селектора в списке.
  • :where(selectorList) — работает точно так же, как :is(), но всегда имеет нулевую специфичность (его стили очень легко переопределить ниже по коду).
  • :has(selector) — родительский селектор. Применяет стили к элементу, если внутри него найден указанный потомок (например, a:has(img) стилизует только те ссылки, внутри которых есть картинка).
  • :dir(direction) — выбор по направлению текста (ltr — слева направо, rtl — справа налево).
  • :lang(language) — выбор элемента по языковому атрибуту (например, :lang(ru)).
  • :target — стилизует элемент, id которого совпадает с хэшем в текущем URL адресной строки (например, #section1). Позволяет делать табы и модальные окна на чистом CSS.

Псевдоэлементы (два двоеточия ::)

  • ::before — создаёт первый виртуальный элемент внутри выбранного тега. Строго требует наличия CSS-свойства content: ""; для отображения.
  • ::after — создаёт последний виртуальный элемент внутри выбранного тега. Также требует свойство content: "";. Часто используется для иконок или декоративных элементов.
  • ::first-letter — стилизует первую букву текста в блоке (создание буквицы).
  • ::first-line — стилизует первую видимую строку текста. Адаптируется при изменении ширины экрана (слова, перенесённые на вторую строку, теряют этот стиль).
  • ::selection — меняет внешний вид текста (обычно цвет фона и шрифта), который пользователь выделил курсором мыши.
  • ::placeholder — стилизует текст-подсказку атрибута placeholder внутри полей ввода.
  • ::marker — позволяет изменить цвет, размер или символ маркера у элементов списка (<li>) или стрелки у тега <summary>.
  • ::backdrop — стилизует область (фон) позади элементов, открытых в полноэкранном режиме (Fullscreen API) или модальных окон (тег <dialog>). Полезно для создания затемнения.
  • ::file-selector-button — позволяет стилизовать стандартную системную кнопку «Выберите файл» внутри <input type="file">.
